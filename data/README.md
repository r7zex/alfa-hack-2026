# Синтетические данные

В основном сценарии нет обращений к реальным банковским или государственным API.
Mock-адаптеры находятся в `app/services/credit_policy.py` и создают ответы ЕГРЮЛ/ЕГРИП,
БКИ и финансового источника. Каждый ответ содержит source, status, synthetic и received_at.
Сценарий выбирается в анкете, сохраняется в БД и воспроизводится при обработке:

| mockScenario | Поведение |
| --- | --- |
| success | Все источники доступны; кредитная политика отдельно оценивает финансы |
| missing | Нет сведений; нужны уточнения |
| negative | Негативные сведения; рекомендация отказа |
| unavailable | Источник недоступен; processing_error и явный повтор |
| malformed | Некорректный ответ; processing_error и явный повтор |

`retry` может явно сменить синтетический сценарий на success. Ранее полученный снимок
сохраняется. Это демонстрационное восстановление, не реальное исправление источника.

Демо-ЮЛ: ИНН 9900000017, демо-ИП: 990000000115. Положительный пример:
месячная выручка 1 500 000, расходы 700 000, платежи по кредитам 10 000,
оборотный кредит 1 000 000 на 12 месяцев. Для альтернативы: кредит 4 000 000,
выручка 1 000 000, расходы 500 000, другие платежи 0. Для отказа: расходы больше выручки.
Используйте синтетические PDF; тестовые документы создаются pyHanko без реальных подписей.

CSV, если они есть в data/, не загружаются автоматически и не считаются готовыми
ML-артефактами. Никакие реальные персональные сведения не нужны для демонстрации.
