# ML и демонстрационная политика

## Два отдельных контракта

1. Worker использует предоставленные native-веса: `FinancialFeaturesProvider → validate_features → score_positive_class → ModelPrediction`. 24 признака, provenance, hash и технический score класса 1 сохраняются на сервере. Target/threshold не установлены. [Model card](model-card.md).
2. Исторический `/api/scoring/{application_id}` предназначен для отдельной ЮЛ-модели банкротства, обученной на собственном CSV. Он требует совместимый локальный артефакт и исходные данные, иначе возвращает контролируемую недоступность. ИП не получает выдуманную модель банкротства. Этот endpoint не подменяет импортированный score.

## Binary Log Loss

`ml/train_legal.py` больше не использует FocalObjective. `LGBMClassifier(objective="binary")`, параметры n_estimators400/learning_rate.05/seed42, кандидаты num_leaves15/31/63. Stratified train/validation/test70/15/15. Максимальный validation AP выбирает модель, validation F2 — порог. Test не участвует в выборе. После фиксации считаются AP, ROC-AUC, Precision, Recall, F1, F2 и confusion matrix по всем трём выборкам.

Артефакт сохраняет feature schema, versions, hashes и параметры в JSON с native LightGBM; старые pickle/Focal artifacts отвергаются с сообщением о переобучении. Пользовательские пути pickle не десериализуются. Опциональное восстановление/обучение по прежнему API остаётся opt-in; обычный запуск ничего не обучает и не скачивает датасет.

Без исходного датасета holdout-метрики не воспроизводились. Указанный в manifest CV PR-AUC относится только к найденной исходной метаинформации.

## Решение по кредиту

`policy_rules.py` не использует score модели в качестве вероятности одобрения. Версия правил сохраняет лимит автоматического решения, полномочий аналитика, долговую нагрузку, денежный запас, минимальный возраст бизнеса и срок предложения. Проверяются документы, стоп-факторы и доступность источников. Авто-одобрение только при выборе auto, достаточном возрасте и сумме в пределах auto_limit. Большие/ручные заявки направляются специалисту; технический отказ не маскируется кредитным отказом.

Default: burden≤50%, cash buffer50 000 ₽, auto≤1.5 млн ₽, аналитик≤5 млн ₽, возраст≥6 месяцев, offer7дней. Это учебные настройки, не политика Альфа-Банка. Овердрафт резервирует principal/months при оценке доступности, а график выплачивает principal в конце.
