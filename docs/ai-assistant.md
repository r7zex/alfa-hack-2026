# ИИ-ассистент: фронтенд

Ветка: `feat/AI-assistant`. Страница клиента: `/#/assistant`.
Пункт "ИИ-ассистент" находится в основном меню рядом с остальными разделами.

Интерфейс реализован в `app/static/js/assistant.mjs`, оформление в
`app/static/assistant.css`. Модуль подключён через существующий роутер в
`app/static/app.js`. Дополнительные зависимости не требуются.

Работают отправка кнопкой и Enter, перенос строки через Shift+Enter,
быстрые вопросы, ссылки в ответах и кнопка "Новый диалог". Пустые сообщения
не отправляются. Длина сообщения ограничена 2000 символами.
Сообщения выводятся с экранированием HTML.

Это только фронтенд. Ответы на быстрые вопросы заранее заданы, для остальных
сообщений показывается уведомление о деморежиме. Подключения к модели,
API чата, БД и анализа пользовательских документов пока нет.
Демонстрационные ответы явно обозначены в интерфейсе.

Переписка и черновик находятся в памяти страницы и сохраняются при переходе
между вкладками. Перезагрузка страницы, выход и смена аккаунта очищают их.
Переписка не записывается в localStorage или sessionStorage.

Для следующего этапа заменить создание демонстрационного ответа в функции
`submit` модуля `assistant.mjs` на вызов будущего API и добавить состояния
ожидания, ошибки и повторной отправки. Серверный контракт пока не задан.

Ручная проверка: войти клиентом, открыть "ИИ-ассистент", выбрать быстрый
вопрос, отправить своё сообщение, перейти в другую вкладку и вернуться.
Проверить сохранение текста черновика, очистку через "Новый диалог" и
отсутствие переписки после выхода и повторного входа.
